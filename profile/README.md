## Standards
- Keep addons/mods **minimal**, dependency-light, and well-documented.
- Prefer **taint-safe / non-invasive** implementations where the platform requires it.
- Releases use **SemVer** + changelogs; public repos avoid personal data, secrets, and local paths.
- Issues should include version, client/build, steps to reproduce, and diagnostics (no account data).
